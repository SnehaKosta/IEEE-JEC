# Put your images here

These files are served from `/images/...`. Missing files fall back gracefully
(gradient backgrounds / text logos), so the site works without them.

| File            | Used for                                  |
| --------------- | ----------------------------------------- |
| `ieee-logo.png` | Header + footer IEEE logo                 |
| `jec-crest.png` | Header + footer college crest             |
| `slide-1.jpg`   | Hero slider, slide 1 (campus building)    |
| `slide-2.jpg`   | Hero slider, slide 2 (students in a lab)  |
| `slide-3.jpg`   | Hero slider, slide 3                      |
| `about.jpg`     | "About" section image (the aircraft photo)|

Recommended: JPG, about 1600px wide for slides, 900px for `about.jpg`.
